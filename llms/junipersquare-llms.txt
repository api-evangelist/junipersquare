# Juniper Square

> Juniper Square is the fund operating system (GPX) for private markets. 2,300+ private markets GPs use its connected technology, unified data, fund administration expertise, and AI to raise capital, streamline fund operations, and improve the LP experience. It exposes a developer API (broad read/write across investor data, fund accounting, payments, compliance, and reporting) and Headless GPX, an official Model Context Protocol (MCP) surface for AI clients.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public Juniper Square surface. Juniper Square does not publish an OpenAPI specification or public developer docs — the developer API is a sales-led, per-customer engagement.

## Agent / MCP access
- Headless GPX connects Claude, Microsoft Copilot, ChatGPT, Gemini, or any MCP-compatible client to a customer's Juniper Square GPX data.
- Provisioned per customer; inherits authentication, permissions (row- and document-level), and audit from the customer's existing configuration.
- Launch read-access domains: contacts, accounts, offerings, prospects, investment entities, positions, subscriptions, documents, activities, communications, transactions.
